# Своё Шеф: Дашборд сезонности

> **Команда «Пушистики»** · Хакатон РСХБ × НИЯУ МИФИ · Кейс №2

---

## Что это такое

**«Своё Шеф: Дашборд сезонности»** — интеллектуальный модуль внутри личного кабинета шеф-повара на платформе [svoe-shef.ru](https://svoe-shef.ru).

Система принимает на вход текущее меню ресторана, определяет тип кухни и текущий сезон, а затем автоматически подбирает сезонные фермерские продукты из каталога [svoe-rodnoe.ru](https://svoe-rodnoe.ru), которые подходят для обновления блюд.

## Ключевая ценность

> Шеф-повар за **15 минут** получает готовый список сезонных фермерских продуктов под свою кухню с AI-объяснениями — вместо **2–3 часов** ручного поиска.

## Главная боль пользователя

Шеф-повар тратит значительное время на ручной поиск сезонных продуктов, не видит целостной картины сезонности и не может быстро найти подходящего фермера под свою концепцию кухни — что **замедляет обновление меню** и снижает конкурентоспособность ресторана.

## Ключевые функции (MVP)

| Функция | Описание |
|---|---|
| 📄 Загрузка меню | PDF или ручной ввод; AI-парсинг и классификация кухни |
| 📅 Тайм-лайн сезонности | Визуальная сетка продукт × месяц на 3 месяца вперёд |
| 🎯 Умный подбор | Фильтрация по кухне, сезону, категории и типу продукта |
| 🤖 AI-объяснения | Почему именно этот продукт подходит для вашей кухни |
| 🌱 Редкие и премиальные | Специальные бейджи для уникальных ингредиентов |
| 👨‍🌾 Переход к фермеру | Прямой переход на карточку на svoe-rodnoe.ru |
| 🛒 Корзина | Сбор и оформление заказа, группировка по фермерам |

## Бизнес-цели (SMART)

| ID | Цель | Метрика | Срок |
|---|---|---|---|
| BG-01 | Сократить время поиска продуктов с ~2 ч до ≤15 мин | Среднее время сессии | MVP + 3 мес. |
| BG-02 | Покрытие ≥80% запросов шефов релевантными предложениями | % запросов с ≥3 результатами | MVP + 3 мес. |
| BG-03 | MAU ≥ 5 000 шефов | MAU в аналитике | MVP + 6 мес. |
| BG-04 | Конверсия «просмотр → фермер» ≥ 25% | CTR кнопки | MVP + 3 мес. |
| BG-05 | Рост B2B-транзакций на svoe-rodnoe.ru на 30% | Заказы с тегом «ресторан» | MVP + 6 мес. |
