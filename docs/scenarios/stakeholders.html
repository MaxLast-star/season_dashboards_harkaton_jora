3. Детальное описание ключевых стейкхолдеров​

SH-01 Шеф-повар​

  • R: Загрузка меню, выбор/корректировка типа кухни, работа с дашбордом, переходы к фермерам
  • C: Определение требований, UX-тестирование прототипа
  • Основная ценность: валидация гипотез через реальное использование

SH-04 Product Manager svoe-shef.ru​

  • A: Все ключевые продуктовые решения (приоритет функций, go/no-go)
  • Главный stakeholder со стороны платформы; его согласование необходимо на каждом этапе

SH-05 Команда svoe-rodnoe.ru​

  • A: Актуализация данных каталога, предоставление API
  • Критичный технический партнёр: без данных о продуктах сервис не работает

SH-07 РСХБ​

  • A: Стратегические решения: финансирование, интеграция экосистемы
  • Финальный арбитр при конфликте интересов платформ

4. Вопросы для стейкхолдеров​

SH-01 Шеф-повар​

  1. Как вы сейчас определяете, какие продукты сезонные? Цель: понять текущий рабочий процесс и выявить «болевые точки»

  2. Сколько времени тратите на обновление меню под сезон? Цель: baseline для KPI BG-01

  3. Какой формат меню используете? PDF, Word, другое? Цель: требования к парсеру меню (FR-MENU-01)

  4. Что важнее при выборе продукта: сезонность, редкость, цена или регион? Цель: приоритеты ранжирования в алгоритме подбора (FR-RECO-01)

  5. Что вы понимаете под «редким» или «премиальным» ингредиентом? Цель: критерии для бейджей (FR-RECO-03)

  6. Готовы ли к AI-объяснениям? Что важно в таком тексте? Цель: доверие к AI-контенту и требования к качеству (риск R6)

SH-04 Product Manager svoe-shef.ru​

  1. Есть ли API для работы с профилями шефов? Какие данные доступны?
  2. Какой технический стек используется на платформе?
  3. Есть ли ограничения на использование AI в продуктах РСХБ?
  4. Каков план интеграции в существующий личный кабинет?

SH-05 Команда svoe-rodnoe.ru​

  1. Есть ли API для доступа к каталогу? Формат данных?
  2. Есть ли поле «сезонность» для каждого продукта?
  3. Каковы ограничения по числу запросов?
  4. Есть ли категоризация продуктов по типу кухни?

SH-06 Фермер​

  1. Как описываете сезонность своей продукции на платформе?
  2. Хотели бы получать уведомления о спросе со стороны ресторанов?
  3. Насколько точно можете прогнозировать наличие продукта на 2–4 недели?
